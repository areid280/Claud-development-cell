# Gate G1 — model choice and licences

**Scope:** tasks T10–T15, `config/models.yaml`, outputs in `jobs/_model_trials/`.
**Purpose:** pick exactly one model per role, approve licences, and refine M2.

## Checklist

1. Every candidate in `config/models.yaml` that T12–T15 tried has a trial folder
   with outputs and a `trial.json` (runtime, VRAM peak, errors).
2. For each **role** (`pose`, `parsing`, `body_measure`, `bg_remove`,
   `image_to_3d`, `face_attrs` if present), compare trial outputs on all
   sample images. Look at the PNG/GLB previews yourself.
3. Choose one model per role (plus one fallback where useful). Set
   `selected: true` on the winners.
4. **Licences.** For each selected model, read the actual licence text
   (model card, LICENSE file, and any weights licence, which may differ from
   the code licence). Record: licence name, commercial use allowed?,
   territory restrictions?, attribution needed? Set `licence_ok: true` only
   if it fits the owner's intended use (ask the human: personal or commercial).
   Watch for: non-commercial research licences on body models and their
   weights; territory exclusions (the owner is in the **UK**); "no use to
   train other models" clauses.
5. VRAM: all selected models must run (one at a time) within 24 GB.
6. Write decision entries in `docs/05_DECISIONS.md` (one per role).
7. Rewrite M2 task cards (T20–T27) so each names the exact selected model,
   wrapper file, install command and expected output shape.

## Then

- Report → `gates/reports/G1_<date>.md`.
