# Gate G0 — environment

**Scope:** tasks T00–T03.
**Purpose:** confirm the pod, repo, tooling and CI are sound before any model work.

## Checklist

1. `bash scripts/doctor.sh` runs clean: Python 3.11, CUDA visible, GPU is an
   NVIDIA card with ≥ 20 GB, Blender 4.x runs headless, disk ≥ 50 GB free on `/workspace`.
2. `python scripts/smoke_test_gpu.py` passes (matrix multiply on GPU, timing printed).
3. `pip install -e ".[dev]"` works in a fresh venv; `ruff check src tests` clean; `pytest -q` green.
4. `avatar-forge --help` and `avatar-forge doctor` work.
5. `avatar-forge run <any image> --confirm-adult-consent --dry-run` creates a job folder with a valid manifest.
6. GitHub Actions CI ran green on the latest push (ask the human for the link if not visible).
7. `.gitignore` excludes `jobs/`, `samples/*` (except README), weights, `.env`, `*.blend1`.
8. No secrets anywhere in the repo: run `git grep -nIE "(api[_-]?key|token|secret|BEGIN [A-Z]+ PRIVATE KEY)"` and inspect hits.
9. `scripts/setup_pod.sh` is idempotent (run it twice; the second run changes nothing).
10. Weights and caches point to `/workspace` so they survive a pod stop.

## Then

- Confirm M1 cards (T10–T15) are still right given the environment. Edit if not.
- Report → `gates/reports/G0_<date>.md`.
