# Gate G2 — MVP end to end

**Scope:** tasks T20–T28. **This is the main go / no-go gate.**

## Checklist

1. `pytest -q` green; CI green.
2. `avatar-forge run samples/<each sample> --confirm-adult-consent` completes
   for all sample images (at least 3), with no `fail` stages.
3. Validation rejects a deliberately bad input (cropped feet) with a clear
   message, and warns on crossed arms.
4. `manifest.json` validates against the schema for every job.
5. Measurements in `s04_body_fit/body_fit.json` are plausible: compare
   height/bust/waist/hips against your visual estimate from the image
   (within ~10%). Note any systematic bias.
6. The fused mesh (`fused/character_fused.fbx`) opens in Blender with no
   errors; check for holes, spikes, floating parts. Render previews exist.
7. The owner imported at least one export into UE5 and sent screenshots
   (ask for them). Judge quality honestly against `docs/00_PROJECT_BRIEF.md` §2.
7b. Front-photo projection (T28, D-016): compare `scripts/preview_sheet.py --compare` before/after; front
   detail clearly sharper, no background bleed or misplaced photo at the silhouette, coverage ≥ 0.7 on
   every sample. The face is judged only as "front texture readable"; the real face is MetaHuman (D-016).
8. Code review: stage contract respected, no hard-coded numbers, models
   loaded lazily, logs useful.
9. Budget check (see report template). **If the outputs aren't promising,
   say so and recommend FAIL or a scope cut rather than continuing.**
