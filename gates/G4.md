# Gate G4 — body editing, normalise, refit, MetaHuman

**Scope:** tasks T40–T45.

## Checklist

1. `avatar-forge rerun <job> --from s05 --set height=175 --set bust=+10%`
   produces new outputs; garments refit without clipping.
2. Normalise: feed a deliberately exaggerated measurement set; the result
   lands inside the ranges in `config/pipeline.yaml` and still looks like
   the same character. Normalise can be turned off.
3. Hair, skin and eye colour overrides change the exported materials / parameters.
4. MetaHuman mapping: the printed or applied parameters produce a MetaHuman
   body close to the measured one (owner screenshots).
5. LODs 0–3 exist with sensible triangle counts (see config).
6. Code review of `body/` rules: ranges are config-driven, documented and tested.
7. Budget check.

## Then

- Rewrite M5 cards (T50–T54).
- Report → `gates/reports/G4_<date>.md`.
